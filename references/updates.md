# Update server

How installed software finds and downloads releases with its user's license key. Docs: https://docs.yard.sh/v1/api/updates/get-latest-update.md (the latest release, in GitHub's release shape), https://docs.yard.sh/v1/api/updates/list-channels.md and https://docs.yard.sh/v1/api/updates/list-releases.md (channel pickers), https://docs.yard.sh/v1/guides/releases/desktop-app-update-channels.md (Stable and Beta end to end). The project must issue license keys (license-keys.md).

- `GET https://api.yard.sh/v1/updates/latest` with `Authorization: Bearer <license key>` or `?license_key=`. The key is the user's own credential, so revocation and activation limits apply and no shared secret ships. Never build a `releases:read` API key into an app: it downloads every public file without a purchase. `assets[].browser_download_url` is a `302` to a short-lived URL. Every update endpoint answers any origin (an Electron or Tauri webview can call it directly); 30 requests a minute per IP.
- `channel=<name>` (case-insensitive) reads that channel's newest published release instead of the project's served one; pins and rollbacks do not apply, so a Stable choice should omit it. A key bought from the project may name any public channel (new channels are private until `yard channels update <name> --visibility public`); a key bought in a sandbox may name only the channel that sandbox follows.
- `sandbox=<name>` reads a sandbox instead of the project (`GET /v1/updates/sandboxes` lists the one scope the key reaches and takes no parameter). A key reaches only where its purchase lives: a sandbox key never reads the project's builds and a real key never reads a sandbox's. A public sandbox of a public, launched project answers any key entitled to it (an open beta stream); anything private or draft answers only the owning team's keys and gives everyone else the same `404` as an unknown name.
- Branch on `error_code`. `403` is about the key or the team's plan (`purchase_incomplete`, `license_refunded`, `license_revoked`, `trial_expired` and `license_subscription_inactive` want a purchase or renewal; `license_validation_disabled` is the team's plan, not the key), so keep the installed build working and show what the code says. `404 license_not_found` is an unknown key, `400 invalid_key_format` a malformed one, `404 project_not_found` / `sandbox_not_found` / `channel_not_found` an unreachable scope, `404 no_releases` nothing published yet, `429 rate_limited` back off.
